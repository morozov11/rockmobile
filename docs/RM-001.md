# Rockmobile RM-001

Rockmobile is a minimal Android internet-radio client built with Jetpack Compose and Media3.

## Что сделано

- Создан Android-проект с Compose UI, списком станций, индикацией текущей станции и мини-плеером.
- Добавлен клиент существующего защищённого RockServer API и настройка адреса/токена в `SettingsRepository`.
- Реализован автоматический переход на встроенный каталог при недоступности сервера, HTTP-ошибках, пустом или некорректном ответе.
- Встроен полный совместимый каталог RockCast: 41 станция, без отдельного вручную поддерживаемого списка.
- Добавлены `MediaSessionService` и Media3/ExoPlayer для фонового воспроизведения, системного уведомления и стандартных media controls.
- Добавлена кнопка повторной попытки подключения к RockServer без перезапуска приложения.
- Добавлены unit-тесты для каталогов, fallback-сценариев, отмены coroutine и состояний ViewModel.

Проверено в среде разработки: `:app:testDebugUnitTest`, `:app:lintDebug` и `:app:assembleDebug` завершились успешно. Ручная проверка на эмуляторе или устройстве остаётся необходимой для подтверждения воспроизведения потока, работы уведомления и lock-screen controls.

## Architecture

`StationsScreen -> StationsViewModel -> StationRepository -> RockserverStationSource / RockcastAssetStationSource` keeps remote-catalogue failure handling separate from individual stream playback. A failed stream is reported by Media3 and never replaces a usable remote catalogue.

`StationsScreen -> PlaybackController -> RockmobileMediaSessionService -> ExoPlayer` keeps ExoPlayer in a `MediaSessionService`. Media3 supplies foreground media notifications, lock-screen controls, headset/Bluetooth media controls, and background playback.

## Remote and bundled catalogues

The remote source calls RockServer's protected `POST /v1/search` endpoint with `{"query":"rock","locale":"en-US","limit":50}` and `Authorization: Bearer <token>`. The response must contain at least one compatible station. Network/DNS/timeout failures, all HTTP failures (including authentication), malformed JSON, incompatible station data, and empty results use the bundled fallback.

[`../app/src/main/assets/stations.txt`](../app/src/main/assets/stations.txt) is the RockCast catalogue in its original text format. Its 41 station data lines are copied from `C:\repos\rockcast\stations.txt`; the format is `name | url | tags | bitrate | codec | country`. Rockmobile derives stable IDs from stream URLs rather than maintaining a divergent hand-written list.

## Connection configuration

`SettingsRepository` is the only connection-settings boundary. The default physical-device URL is
`http://192.168.31.133:3000`, the current laptop LAN address where RockServer listens. The Android
Emulator alias remains `http://10.0.2.2:3000` in `DEFAULT_EMULATOR_URL`. Until user accounts and
revocable client tokens are introduced, the app uses the stable bootstrap token
`rockserver-dev-bootstrap-7f4b9a2c1e6d8a40`, matching RockServer's fallback.
`SettingsRepository.updateRockserver(url, bearerToken)` remains available for an explicit override.

For a physical device, configure the computer's reachable LAN address and bind RockServer to that interface; `10.0.2.2` is emulator-only.

## Build and manual verification

Run `gradlew.bat :app:testDebugUnitTest` and `gradlew.bat :app:lintDebug`.

1. Start RockServer with its bearer token and make it reachable from an emulator/device.
2. Install with `gradlew.bat :app:installDebug`.
3. Select a station, background or lock the device, and use the notification to play/pause. Return to the app and confirm the mini player state.
4. Stop RockServer and relaunch. The bundled-catalogue warning and 41 fallback stations should appear. Start RockServer again and tap **Retry Rockserver** to switch back without restarting.

The source/unit tests cover catalogue parsing, remote success/error mapping, repository fallback and cancellation, plus ViewModel remote/fallback/fatal/retry state transitions. Device playback and notification steps require an emulator or physical device and are not substituted by unit tests.
