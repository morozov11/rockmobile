## Cutover state

RockCatalog is the only authoring source for the curated baseline. RockServer consumes the same
immutable baseline first, while RockMobile uses RockServer when available and otherwise opens its
verified extended SQLite package; an absent, corrupt, incompatible, or rejected extended package
falls back to the independently verified 41-station baseline. No `stations.txt` parser or manual
catalog-copy path remains in RockMobile. Rollback is a reviewed `release_sync.py` pin to a retained
prior immutable baseline and, where needed, its matching retained extended manifest/package.
